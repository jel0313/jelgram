### STEP 3:`app/core/db.py` を作り、DB に接続できるか確かめる

📘 設計:詳細設計書 3章・6.2

`app/core/db.py` を新規作成し、次の内容を書く。

```python
"""DB 接続(エンジン・セッション)と、ORM モデルの親クラス。"""

from collections.abc import Iterator
from functools import lru_cache
from typing import Annotated

from fastapi import Depends
from sqlalchemy import create_engine
from sqlalchemy.engine import Engine
from sqlalchemy.orm import DeclarativeBase, Session

from app.core.config import get_settings


class Base(DeclarativeBase):
    """すべての ORM モデルの親クラス。

    テーブルの作成・変更はマイグレーション(supabase/migrations)で行う。
    Base.metadata.create_all() は使わない。
    """


@lru_cache
def get_engine() -> Engine:
    """エンジン(コネクションプール)を返す。アプリ全体で1つを使い回す。"""
    settings = get_settings()
    return create_engine(settings.sqlalchemy_database_url, pool_pre_ping=True)


def get_db() -> Iterator[Session]:
    """リクエストごとに DB セッションを渡し、終わったら閉じる(接続をプールに返す)。"""
    with Session(get_engine()) as session:
        yield session


DbSessionDep = Annotated[Session, Depends(get_db)]
```

<details>
<summary>🔰 1行ずつの解説(クリックで開く)</summary>

| コード | 何をしているか |
| --- | --- |
| `from collections.abc import Iterator` | `yield` する関数の戻り値の型 |
| `from functools import lru_cache` | 関数の結果を覚えておく道具 |
| `from typing import Annotated` | 「型 + `Depends(...)`」をまとめて書く道具(4.2 の `CurrentUserDep` と同じ) |
| `from fastapi import Depends` | 依存関数を指定する |
| `from sqlalchemy import create_engine` | エンジン(接続の置き場 = プールを持つもの)を作る関数 |
| `from sqlalchemy.engine import Engine` | エンジンの型 |
| `from sqlalchemy.orm import DeclarativeBase, Session` | モデルの親クラスの元と、セッション(DB との 1 回分の会話)のクラス |
| `from app.core.config import get_settings` | 設定を返す関数 |
| `class Base(DeclarativeBase):` | すべてのモデル(`Profile`・`Post`・`Like`、4.5 の `ChatMessage`)の共通の親クラス。これを継承したクラスが、SQLAlchemy にテーブルとして登録される |
| `"""すべての ORM モデルの親クラス。…"""` | クラスの説明文。説明文があるので、中身の `pass` は書かなくてよい |
| `@lru_cache` | 結果を覚えておく印。これでエンジン(= プール)がアプリ全体で 1 つだけになる |
| `def get_engine() -> Engine:` | エンジンを返す関数 |
| `settings = get_settings()` | 設定を読む |
| `return create_engine(settings.sqlalchemy_database_url, pool_pre_ping=True)` | STEP 2 で作った接続文字列でエンジンを作る。`pool_pre_ping=True` は「接続を借りる前に、まだつながっているか確かめる」。この時点ではまだ DB に接続しない(最初に SQL を実行したときに接続する) |
| `def get_db() -> Iterator[Session]:` | リクエストごとにセッションを渡す依存関数 |
| `with Session(get_engine()) as session:` | セッションを作る。`with` のブロックを抜けると、セッションが自動で閉じて接続がプールに返る |
| `yield session` | エンドポイントにセッションを渡して、ここで一時停止する。エンドポイントの処理が終わると続きから再開し、`with` を抜けて片付けが行われる(エラーのときも必ず片付く) |
| `DbSessionDep = Annotated[Session, Depends(get_db)]` | 「`get_db` が渡すセッション」を 1 語で書ける別名。各 API は `session: DbSessionDep` と書くだけでよい |

</details>

```python
"""ユーザーの ORM モデル(supabase/migrations の profiles と同じ形)。"""

from datetime import datetime
from uuid import UUID

from sqlalchemy import DateTime, Text, func
from sqlalchemy.orm import Mapped, mapped_column

from app.core.db import Base


class Profile(Base):
    __tablename__ = "profiles"

    id: Mapped[UUID] = mapped_column(primary_key=True)
    display_name: Mapped[str] = mapped_column(Text)
    avatar_url: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
```

<details>
<summary>🔰 1行ずつの解説(クリックで開く)</summary>

| コード | 何をしているか |
| --- | --- |
| `from datetime import datetime` | 日時の型 |
| `from uuid import UUID` | UUID の型 |
| `from sqlalchemy import DateTime, Text, func` | 列の型(`DateTime`・`Text`)と、SQL の関数を呼ぶ道具(`func`) |
| `from sqlalchemy.orm import Mapped, mapped_column` | 列の型を書く `Mapped` と、列の詳細を書く `mapped_column` |
| `from app.core.db import Base` | STEP 3 で作った、全モデルの親クラス |
| `class Profile(Base):` | `Base` を引き継いだ、`profiles` テーブル用のクラス |
| `__tablename__ = "profiles"` | このクラスが対応するテーブル名 |
| `id: Mapped[UUID] = mapped_column(primary_key=True)` | 列 `id`。型は UUID で、主キー(1 行を特定する列) |
| `display_name: Mapped[str] = mapped_column(Text)` | 列 `display_name`。`Mapped[str]` は「文字列で、NULL は不可」。`Text` は DB の `text` 型(長さの制限なし) |
| `avatar_url: Mapped[str \| None] = mapped_column(Text)` | `str \| None` なので NULL を入れてよい列 |
| `created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())` | タイムゾーン付きの日時(DB の `timestamptz`)。`server_default=func.now()` は「値を入れなければ、DB が現在時刻を入れる」。`timezone=True` を忘れると 9 時間ずれる原因になる |

</details>

```python
"""投稿・いいねの ORM モデル(supabase/migrations の posts・likes と同じ形)。"""

from datetime import datetime
from uuid import UUID

from sqlalchemy import BigInteger, DateTime, ForeignKey, Identity, Text, func
from sqlalchemy.orm import Mapped, mapped_column

from app.core.db import Base
from app.users.models import Profile


class Post(Base):
    __tablename__ = "posts"

    id: Mapped[int] = mapped_column(BigInteger, Identity(always=True), primary_key=True)
    user_id: Mapped[UUID] = mapped_column(ForeignKey(Profile.id))
    content: Mapped[str] = mapped_column(Text)
    image_url: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())


class Like(Base):
    __tablename__ = "likes"

    user_id: Mapped[UUID] = mapped_column(ForeignKey(Profile.id), primary_key=True)
    post_id: Mapped[int] = mapped_column(BigInteger, ForeignKey(Post.id), primary_key=True)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
```

<details>
<summary>🔰 1行ずつの解説(クリックで開く)</summary>

| コード | 何をしているか |
| --- | --- |
| `from sqlalchemy import BigInteger, DateTime, ForeignKey, Identity, Text, func` | Profile で使ったものに加えて、大きな整数(`BigInteger`)・外部キー(`ForeignKey`)・自動採番(`Identity`) |
| `from app.users.models import Profile` | 外部キーの参照先として、② の `Profile` を使う |
| `id: Mapped[int] = mapped_column(BigInteger, Identity(always=True), primary_key=True)` | 大きな整数(`bigint`)の主キー。`Identity(always=True)` は「番号は DB が自動で振る(自分では入れない)」 |
| `user_id: Mapped[UUID] = mapped_column(ForeignKey(Profile.id))` | 投稿者。`ForeignKey(Profile.id)` は「`profiles` の `id` に存在する値しか入れられない」(外部キー)。文字列の `"profiles.id"` ではなく、クラスの列で指定している(`Profile` が必ず先に読み込まれるので安全) |
| `content`・`image_url`・`created_at` の行 | Profile と同じ書き方。`image_url` だけ NULL 可 |
| `class Like(Base):` / `__tablename__ = "likes"` | `likes` テーブル用のクラス |
| `user_id: Mapped[UUID] = mapped_column(ForeignKey(Profile.id), primary_key=True)` | いいねした人。主キーの 1 つ目 |
| `post_id: Mapped[int] = mapped_column(BigInteger, ForeignKey(Post.id), primary_key=True)` | いいねされた投稿。主キーの 2 つ目。2 つの列の **組み合わせ** が主キーになるので、同じ人が同じ投稿に 2 回いいねすることはできない |

</details>

`supabase/migrations/20260928000000_initial_schema.sql` と見比べて、列名が同じになっていることを確かめる。

```python
"""投稿・いいねの例外。

HTTPException を継承しているので、service で raise するとそのままエラーの応答になる。
"""

from fastapi import HTTPException


class PostNotFoundError(HTTPException):
    def __init__(self) -> None:
        super().__init__(status_code=404, detail="投稿が見つかりません")


class InvalidImageUrlError(HTTPException):
    def __init__(self) -> None:
        super().__init__(status_code=422, detail="画像の URL が不正です")
```

<details>
<summary>🔰 1行ずつの解説(クリックで開く)</summary>

| コード | 何をしているか |
| --- | --- |
| `from fastapi import HTTPException` | 投げるとエラーの応答になる例外。これを引き継いで、この機能用のエラーを作る |
| `class PostNotFoundError(HTTPException):` | 「投稿が見つからない」エラーのクラス。`HTTPException` を引き継ぐ |
| `def __init__(self) -> None:` | `__init__` は、クラスからオブジェクトを作るときに自動で呼ばれる特別なメソッド。`PostNotFoundError()` と書いた瞬間に動く |
| `super().__init__(status_code=404, detail="投稿が見つかりません")` | `super()` は親クラス(`HTTPException`)のこと。親の `__init__` にステータスとメッセージを渡して、404 のエラーとして初期化する |
| `class InvalidImageUrlError(HTTPException):` と 2 行 | 同じ書き方で、422「画像の URL が不正です」のエラー |

</details>

- 使う側は `raise PostNotFoundError()` と書くだけで、404 と決まったメッセージが返る

```python
"""投稿・いいねの DB アクセス。SQL はこのファイルにだけ書く。

確定(commit)はしない。確定は service が行う。
"""

from uuid import UUID

from sqlalchemy import Row, Select, delete, exists, func, select
from sqlalchemy.dialects.postgresql import insert
from sqlalchemy.orm import Session

from app.posts.models import Like, Post
from app.users.models import Profile


def _post_query(user_id: UUID) -> Select:
    """投稿・投稿者・いいね数・自分がいいね済みか を 1 回の SQL で取る。"""
    like_count = select(func.count()).where(Like.post_id == Post.id).scalar_subquery()
    liked_by_me = exists().where(Like.post_id == Post.id, Like.user_id == user_id)
    return select(
        Post,
        Profile,
        like_count.label("like_count"),
        liked_by_me.label("liked_by_me"),
    ).join(Profile, Post.user_id == Profile.id)


def find_timeline(session: Session, user_id: UUID, limit: int) -> list[Row]:
    """新しい順(同じ時刻なら id の大きい順)に、最大 limit 件を取る。"""
    stmt = _post_query(user_id).order_by(Post.created_at.desc(), Post.id.desc()).limit(limit)
    return list(session.execute(stmt).all())


def find_post_row(session: Session, post_id: int, user_id: UUID) -> Row:
    """投稿 1 件を、タイムラインと同じ形で取る。"""
    return session.execute(_post_query(user_id).where(Post.id == post_id)).one()


def exists_post(session: Session, post_id: int) -> bool:
    return session.get(Post, post_id) is not None


def insert_post(session: Session, user_id: UUID, content: str, image_url: str | None) -> Post:
    """投稿を追加する。flush で DB に送り、DB が振った id を受け取る(確定はしない)。"""
    post = Post(user_id=user_id, content=content, image_url=image_url)
    session.add(post)
    session.flush()
    return post


def insert_like(session: Session, post_id: int, user_id: UUID) -> None:
    """いいねを追加する。すでにあれば何もしない。"""
    session.execute(insert(Like).values(user_id=user_id, post_id=post_id).on_conflict_do_nothing())


def delete_like(session: Session, post_id: int, user_id: UUID) -> None:
    """いいねを削除する。なければ何もしない。"""
    session.execute(delete(Like).where(Like.user_id == user_id, Like.post_id == post_id))


def count_likes(session: Session, post_id: int) -> int:
    return session.scalar(select(func.count()).select_from(Like).where(Like.post_id == post_id))


def is_liked(session: Session, post_id: int, user_id: UUID) -> bool:
    return session.scalar(select(exists().where(Like.post_id == post_id, Like.user_id == user_id)))
```

```python
"""投稿・いいねの業務ロジック。

入力のチェック・DB の確定(commit)・応答の形への詰め替えを行う。SQL は repository に任せる。
"""

from uuid import UUID

from sqlalchemy import Row
from sqlalchemy.orm import Session

from app.core.config import Settings
from app.posts import repository
from app.posts.constants import TIMELINE_LIMIT
from app.posts.exceptions import InvalidImageUrlError, PostNotFoundError
from app.posts.schemas import AuthorResponse, LikeResponse, PostCreate, PostResponse


def _to_post_response(row: Row) -> PostResponse:
    """repository の 1 行(投稿, 投稿者, いいね数, いいね済みか)を応答の形にする。"""
    post, profile, like_count, liked_by_me = row
    return PostResponse(
        id=post.id,
        content=post.content,
        image_url=post.image_url,
        created_at=post.created_at,
        author=AuthorResponse(
            id=profile.id,
            display_name=profile.display_name,
            avatar_url=profile.avatar_url,
        ),
        like_count=like_count,
        liked_by_me=liked_by_me,
    )


def _ensure_post_exists(session: Session, post_id: int) -> None:
    if not repository.exists_post(session, post_id):
        raise PostNotFoundError()


def _like_response(session: Session, post_id: int, user_id: UUID) -> LikeResponse:
    return LikeResponse(
        post_id=post_id,
        like_count=repository.count_likes(session, post_id),
        liked_by_me=repository.is_liked(session, post_id, user_id),
    )


def get_timeline(session: Session, user_id: UUID) -> list[PostResponse]:
    rows = repository.find_timeline(session, user_id, TIMELINE_LIMIT)
    return [_to_post_response(row) for row in rows]


def create_post(
    session: Session, user_id: UUID, body: PostCreate, settings: Settings
) -> PostResponse:
    """投稿する。画像は自分の Storage バケットの URL だけを受け付ける。"""
    bucket_url = (
        f"{settings.supabase_url}/storage/v1/object/public/{settings.supabase_storage_bucket}/"
    )
    if body.image_url is not None and not body.image_url.startswith(bucket_url):
        raise InvalidImageUrlError()

    post = repository.insert_post(session, user_id, body.content, body.image_url)
    session.commit()
    return _to_post_response(repository.find_post_row(session, post.id, user_id))


def like_post(session: Session, post_id: int, user_id: UUID) -> LikeResponse:
    """いいねする。いいね済みなら何もしない。"""
    _ensure_post_exists(session, post_id)
    repository.insert_like(session, post_id, user_id)
    session.commit()
    return _like_response(session, post_id, user_id)


def unlike_post(session: Session, post_id: int, user_id: UUID) -> LikeResponse:
    """いいねを取り消す。いいねしていなければ何もしない。"""
    _ensure_post_exists(session, post_id)
    repository.delete_like(session, post_id, user_id)
    session.commit()
    return _like_response(session, post_id, user_id)
```

```python
窓口の役割だけを持つ。処理は service に任せる。

from fastapi import APIRouter

from app.auth.dependencies import CurrentUserDep
from app.core.config import SettingsDep
from app.core.db import DbSessionDep

from app.posts.schemas import LikeResponse, PostCreate, PostResponse

router = APIRouter(prefix="/posts", tags=["posts"])


@router.get("", response_model=list[PostResponse])

) -> PostResponse:
    """投稿する。"""
    return service.create_post(session, user.id, body, settings)

    return service.like_post(session, post_id, user.id)


@router.delete("/{post_id}/like", response_model=LikeResponse)
def unlike_post(post_id: int, user: CurrentUserDep, session: DbSessionDep) -> LikeResponse:
```

| `liked_id = ...` / `not_liked_id = ...` | A が 2 つ投稿する |
| `db_client.post(f"/posts/{liked_id}/like")` | A が 1 つ目にいいね |
| `login_as(user_b)` → `db_client.post(f"/posts/{liked_id}/like")` | B に切り替えて、1 つ目にいいね(いいね数 2) |
| `return {"a": user_a, "c": user_c, "liked_id": liked_id, "not_liked_id": not_liked_id}` | テストで使う値を辞書で返す |
| `login_as(liked_posts["a"])` | T-05:A でログインしてタイムラインを見る |
| `liked = _find(posts, liked_posts["liked_id"])` | いいねされた投稿を探す |
| `assert (liked["like_count"], liked["liked_by_me"]) == (2, True)` | 2 つの値をまとめて比べる。いいね数 2 で、A はいいね済み |
| `login_as(liked_posts["c"])` | T-06:いいねしていない C でログイン |
| `assert (liked["like_count"], liked["liked_by_me"]) == (2, False)` | いいね数は 2 のまま、でも C はいいねしていない |

**T-07〜T-11:本文と画像 URL のチェック**

| コード | 何をしているか |
| --- | --- |
| `json={"content": "  やあ  "}` | 前後に空白のある本文(T-07) |
| `assert response.json()["content"] == "やあ"` | 空白が除かれて保存されたか |
| `pytest.param("", id="empty")` など 3 つ | 空・空白だけ・501 文字の 3 パターン(T-08)。`"x" * 501` は x を 501 個並べた文字列 |
| `assert response.status_code == 422` | 3 パターンとも 422 |
| `json={"content": "x" * 500}` | ちょうど 500 文字(T-09)。上限ぴったりは OK か |
| `json={"content": "画像付き", "image_url": MY_BUCKET_IMAGE_URL}` | 自分のバケットの画像 URL(T-10) |
| `"image_url": "https://evil.example.com/a.jpg"` | 他のサイトの画像 URL(T-11) |
| `assert response.json() == {"detail": "画像の URL が不正です"}` | 決めたメッセージが返るか |

**T-12〜T-14:いいね・取り消し**

| コード | 何をしているか |
| --- | --- |
| `for _ in range(2):` | 2 回繰り返す。回数を数える変数は使わないので `_` にする |
| `response = db_client.post(f"/posts/{post_id}/like")` | いいねする(2 回) |
| `assert response.json() == {"post_id": post_id, "like_count": 1, "liked_by_me": True}` | 2 回目も、いいね数は 1 のまま |
| `db_client.post(f"/posts/{post_id}/like")` → `for` の中で `db_client.delete(...)` | いいねしてから、取り消しを 2 回(T-13) |
| `@pytest.mark.parametrize("method", ["POST", "DELETE"])` | POST と DELETE の 2 回実行する(T-14) |
| `response = db_client.request(method, "/posts/999999999/like")` | 存在しない投稿にいいね・取り消しをする |
| `assert response.json() == {"detail": "投稿が見つかりません"}` | 404 と決めたメッセージが返るか |

## 困ったときは

| 症状                                                                                  | 原因と対処                                                                                                                                         |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ModuleNotFoundError: No module named 'psycopg2'`                                     | 接続文字列が `postgresql://` のまま。`create_engine` に `sqlalchemy_database_url`(`+psycopg` 付き)を渡しているか確認                             |
| 接続時に `connection timeout` や `could not translate host name`                      | 開発用の Supabase が一時停止している、またはネットワークの問題。管理画面でプロジェクトを開き、停止中なら再開する                                   |
| 接続時に `password authentication failed`                                             | `.env` の `DATABASE_URL` のパスワードが違う。再発行した場合は書き換え忘れがないか確認                                                               |
| `Port could not be cast to integer` / 接続文字列の解析エラー                           | DB のパスワードに記号(`?` `/` `@` など)が入っている。英数字だけのパスワードに再発行する                                                          |
| `POST /posts` で `500` と `ForeignKeyViolation`                                        | ログイン中のユーザーの `profiles` がない。3.2 のトリガーが動いているか、Table Editor の `profiles` で確認する                                      |
| 日時が 9 時間ずれる                                                                   | `DateTime(timezone=True)` を付け忘れている                                                                                                         |
| `AttributeError: 'Insert' object has no attribute 'on_conflict_do_nothing'`           | `insert` を `sqlalchemy` から読み込んでいる。`from sqlalchemy.dialects.postgresql import insert` にする                                             |
| いいねを 2 回押すと `500` と `UniqueViolation`                                        | `on_conflict_do_nothing()` を付けていない                                                                                                          |
| T-04 がたまに失敗する                                                                 | 並び順に `Post.id.desc()` がない(詳細設計書 8.1 のつまずきポイント)                                                                              |
| テスト用ユーザーが DB に残っている(STEP 12 の SQL が 0 にならない)                  | `db_session` の片付けで `transaction.rollback()` していない、または `db_client` ではなく `client` で投稿している。Table Editor で残ったユーザーを削除してから直す |
| `test_posts.py` だけなら通るのに、全部まとめて実行すると失敗する                      | 差し替えを戻していない。`db_client` の `yield` の後で `app.dependency_overrides.clear()` する                                                      |
| テストで `ValidationError` と `database_url` が出る                                   | conftest.py から `DATABASE_URL` の行を消したのに、`.env` に `DATABASE_URL` がない。`.env` を確認する                                              |
| Ruff の format で `core/config.py` が直される                                              | STEP 2 で足したプロパティの前の空行が 2 行になっている。`ruff format` が 1 行に直すので、そのままでよい                                             |
| `/docs` で `post_id` に数字以外を入れると `422`                                       | 正常。パスの `post_id: int` を FastAPI が自動でチェックしている                                                                                    |
