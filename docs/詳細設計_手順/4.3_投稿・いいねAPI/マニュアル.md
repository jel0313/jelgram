### STEP 3:`app/db.py` を作り、DB に接続できるか確かめる

📘 設計:詳細設計書 3章・6.2

`app/db.py` を新規作成し、次の内容を書く。

```python
"""DB 接続(エンジン・セッション)。"""

from collections.abc import Iterator
from functools import lru_cache
from typing import Annotated

from fastapi import Depends
from sqlalchemy import create_engine
from sqlalchemy.engine import Engine
from sqlalchemy.orm import Session

from app.config import get_settings


@lru_cache
def get_engine() -> Engine:
    """エンジン(コネクションプール)を返す。アプリ全体で1つを使い回す。"""
    settings = get_settings()
    return create_engine(settings.sqlalchemy_database_url, pool_pre_ping=True)


def get_db() -> Iterator[Session]:
    """リクエストごとに DB セッションを渡し、終わったら閉じる(接続をプールに返す)。"""
    with Session(get_engine()) as session:
        yield session


DbSessionDep = Annotated[Session, Depends(get_db)]
```

<details>
<summary>🔰 1行ずつの解説(クリックで開く)</summary>

| コード | 何をしているか |
| --- | --- |
| `from collections.abc import Iterator` | `yield` する関数の戻り値の型 |
| `from functools import lru_cache` | 関数の結果を覚えておく道具 |
| `from typing import Annotated` | 「型 + `Depends(...)`」をまとめて書く道具(4.2 の `CurrentUserDep` と同じ) |
| `from fastapi import Depends` | 依存関数を指定する |
| `from sqlalchemy import create_engine` | エンジン(接続の置き場 = プールを持つもの)を作る関数 |
| `from sqlalchemy.engine import Engine` | エンジンの型 |
| `from sqlalchemy.orm import Session` | セッション(DB との 1 回分の会話)のクラス |
| `from app.config import get_settings` | 設定を返す関数 |
| `@lru_cache` | 結果を覚えておく印。これでエンジン(= プール)がアプリ全体で 1 つだけになる |
| `def get_engine() -> Engine:` | エンジンを返す関数 |
| `settings = get_settings()` | 設定を読む |
| `return create_engine(settings.sqlalchemy_database_url, pool_pre_ping=True)` | STEP 2 で作った接続文字列でエンジンを作る。`pool_pre_ping=True` は「接続を借りる前に、まだつながっているか確かめる」。この時点ではまだ DB に接続しない(最初に SQL を実行したときに接続する) |
| `def get_db() -> Iterator[Session]:` | リクエストごとにセッションを渡す依存関数 |
| `with Session(get_engine()) as session:` | セッションを作る。`with` のブロックを抜けると、セッションが自動で閉じて接続がプールに返る |
| `yield session` | エンドポイントにセッションを渡して、ここで一時停止する。エンドポイントの処理が終わると続きから再開し、`with` を抜けて片付けが行われる(エラーのときも必ず片付く) |
| `DbSessionDep = Annotated[Session, Depends(get_db)]` | 「`get_db` が渡すセッション」を 1 語で書ける別名。各 API は `session: DbSessionDep` と書くだけでよい |

</details>

### STEP 4:`app/models.py` を作る

📘 設計:詳細設計書 6.3

`app/models.py` を新規作成し、次の内容を書く。

```python
"""ORM モデル(supabase/migrations のテーブル定義と同じ形)。

テーブルの作成・変更はマイグレーションで行う。Base.metadata.create_all() は使わない。
"""

from datetime import datetime
from uuid import UUID

from sqlalchemy import BigInteger, DateTime, ForeignKey, Identity, Text, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class Base(DeclarativeBase):
    pass


class Profile(Base):
    __tablename__ = "profiles"

    id: Mapped[UUID] = mapped_column(primary_key=True)
    display_name: Mapped[str] = mapped_column(Text)
    avatar_url: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())


class Post(Base):
    __tablename__ = "posts"

    id: Mapped[int] = mapped_column(BigInteger, Identity(always=True), primary_key=True)
    user_id: Mapped[UUID] = mapped_column(ForeignKey("profiles.id"))
    content: Mapped[str] = mapped_column(Text)
    image_url: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())


class Like(Base):
    __tablename__ = "likes"

    user_id: Mapped[UUID] = mapped_column(ForeignKey("profiles.id"), primary_key=True)
    post_id: Mapped[int] = mapped_column(BigInteger, ForeignKey("posts.id"), primary_key=True)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
```

<summary>🔰 1行ずつの解説(クリックで開く)</summary>

**読み込みと親クラス**

| コード | 何をしているか |
| --- | --- |
| `from datetime import datetime` | 日時の型 |
| `from uuid import UUID` | UUID の型 |
| `from sqlalchemy import BigInteger, DateTime, ForeignKey, Identity, Text, func` | 列の型(`BigInteger`・`DateTime`・`Text`)、外部キー(`ForeignKey`)、自動採番(`Identity`)、SQL の関数を呼ぶ道具(`func`) |
| `from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column` | モデルの親クラス、列の型を書く `Mapped`、列の詳細を書く `mapped_column` |
| `class Base(DeclarativeBase):` | すべてのモデルの親クラスを作る |
| `pass` | 「中身は何も書かない」という意味。親クラスとして使うだけなので空でよい |

**Profile(profiles テーブル)**

| コード | 何をしているか |
| --- | --- |
| `class Profile(Base):` | `Base` を引き継いだ、`profiles` テーブル用のクラス |
| `__tablename__ = "profiles"` | このクラスが対応するテーブル名 |
| `id: Mapped[UUID] = mapped_column(primary_key=True)` | 列 `id`。型は UUID で、主キー(1 行を特定する列) |
| `display_name: Mapped[str] = mapped_column(Text)` | 列 `display_name`。`Mapped[str]` は「文字列で、NULL は不可」。`Text` は DB の `text` 型(長さの制限なし) |
| `avatar_url: Mapped[str \| None] = mapped_column(Text)` | `str \| None` なので NULL を入れてよい列 |
| `created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())` | タイムゾーン付きの日時(DB の `timestamptz`)。`server_default=func.now()` は「値を入れなければ、DB が現在時刻を入れる」。`timezone=True` を忘れると 9 時間ずれる原因になる |

**Post(posts テーブル)**

| コード | 何をしているか |
| --- | --- |
| `id: Mapped[int] = mapped_column(BigInteger, Identity(always=True), primary_key=True)` | 大きな整数(`bigint`)の主キー。`Identity(always=True)` は「番号は DB が自動で振る(自分では入れない)」 |
| `user_id: Mapped[UUID] = mapped_column(ForeignKey("profiles.id"))` | 投稿者。`ForeignKey("profiles.id")` は「`profiles` の `id` に存在する値しか入れられない」(外部キー) |
| `content`・`image_url`・`created_at` の行 | Profile と同じ書き方。`image_url` だけ NULL 可 |

**Like(likes テーブル)**

| コード | 何をしているか |
| --- | --- |
| `user_id: Mapped[UUID] = mapped_column(ForeignKey("profiles.id"), primary_key=True)` | いいねした人。主キーの 1 つ目 |
| `post_id: Mapped[int] = mapped_column(BigInteger, ForeignKey("posts.id"), primary_key=True)` | いいねされた投稿。主キーの 2 つ目。2 つの列の **組み合わせ** が主キーになるので、同じ人が同じ投稿に 2 回いいねすることはできない |
| `created_at` の行 | いいねした日時 |

### STEP 5:`app/routers/posts.py` を作り、`main.py` に登録する

📘 設計:詳細設計書 6.4・6.5

**① `app/routers/posts.py` を新規作成**

```python
"""投稿・いいね API。"""

from datetime import datetime
from typing import Annotated
from uuid import UUID

from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel, StringConstraints
from sqlalchemy import Row, Select, delete, exists, func, select
from sqlalchemy.dialects.postgresql import insert
from sqlalchemy.orm import Session

from app.auth import CurrentUserDep
from app.config import Settings, get_settings
from app.db import DbSessionDep
from app.models import Like, Post, Profile

# 本文の最大文字数(前後の空白を除いた長さ)
CONTENT_MAX_LENGTH = 500
# タイムラインで返す最大件数(ページングは 2 次開発)
TIMELINE_LIMIT = 50

router = APIRouter(tags=["posts"])


class AuthorResponse(BaseModel):
    id: UUID
    display_name: str
    avatar_url: str | None


class PostResponse(BaseModel):
    id: int
    content: str
    image_url: str | None
    created_at: datetime
    author: AuthorResponse
    like_count: int
    liked_by_me: bool


class PostCreate(BaseModel):
    content: Annotated[
        str,
        StringConstraints(strip_whitespace=True, min_length=1, max_length=CONTENT_MAX_LENGTH),
    ]
    image_url: str | None = None


class LikeResponse(BaseModel):
    post_id: int
    like_count: int
    liked_by_me: bool


def _post_query(user_id: UUID) -> Select:
    """投稿・投稿者・いいね数・自分がいいね済みか を 1 回の SQL で取る。"""
    like_count = select(func.count()).where(Like.post_id == Post.id).scalar_subquery()
    liked_by_me = exists().where(Like.post_id == Post.id, Like.user_id == user_id)
    return select(
        Post,
        Profile,
        like_count.label("like_count"),
        liked_by_me.label("liked_by_me"),
    ).join(Profile, Post.user_id == Profile.id)


def _to_post_response(row: Row) -> PostResponse:
    """_post_query の 1 行(投稿, 投稿者, いいね数, いいね済みか)を応答の形にする。"""
    post, profile, like_count, liked_by_me = row
    return PostResponse(
        id=post.id,
        content=post.content,
        image_url=post.image_url,
        created_at=post.created_at,
        author=AuthorResponse(
            id=profile.id,
            display_name=profile.display_name,
            avatar_url=profile.avatar_url,
        ),
        like_count=like_count,
        liked_by_me=liked_by_me,
    )


def _ensure_post_exists(session: Session, post_id: int) -> None:
    if session.get(Post, post_id) is None:
        raise HTTPException(status_code=404, detail="投稿が見つかりません")


def _like_response(session: Session, post_id: int, user_id: UUID) -> LikeResponse:
    """いいね操作の後の、いいね数と自分がいいね済みかを返す。"""
    like_count = session.scalar(
        select(func.count()).select_from(Like).where(Like.post_id == post_id)
    )
    liked_by_me = session.scalar(
        select(exists().where(Like.post_id == post_id, Like.user_id == user_id))
    )
    return LikeResponse(post_id=post_id, like_count=like_count, liked_by_me=liked_by_me)


@router.get("/posts", response_model=list[PostResponse])
def list_posts(user: CurrentUserDep, session: DbSessionDep) -> list[PostResponse]:
    """タイムライン(新しい順・最大 TIMELINE_LIMIT 件)。"""
    stmt = (
        _post_query(user.id).order_by(Post.created_at.desc(), Post.id.desc()).limit(TIMELINE_LIMIT)
    )
    return [_to_post_response(row) for row in session.execute(stmt).all()]


@router.post("/posts", response_model=PostResponse, status_code=201)
def create_post(
    body: PostCreate,
    user: CurrentUserDep,
    session: DbSessionDep,
    settings: Annotated[Settings, Depends(get_settings)],
) -> PostResponse:
    """投稿する。画像は自分の Storage バケットの URL だけを受け付ける。"""
    bucket_url = (
        f"{settings.supabase_url}/storage/v1/object/public/{settings.supabase_storage_bucket}/"
    )
    if body.image_url is not None and not body.image_url.startswith(bucket_url):
        raise HTTPException(status_code=422, detail="画像の URL が不正です")

    post = Post(user_id=user.id, content=body.content, image_url=body.image_url)
    session.add(post)
    session.commit()

    row = session.execute(_post_query(user.id).where(Post.id == post.id)).one()
    return _to_post_response(row)


@router.post("/posts/{post_id}/like", response_model=LikeResponse)
def like_post(post_id: int, user: CurrentUserDep, session: DbSessionDep) -> LikeResponse:
    """いいねする。いいね済みなら何もしない。"""
    _ensure_post_exists(session, post_id)
    session.execute(insert(Like).values(user_id=user.id, post_id=post_id).on_conflict_do_nothing())
    session.commit()
    return _like_response(session, post_id, user.id)


@router.delete("/posts/{post_id}/like", response_model=LikeResponse)
def unlike_post(post_id: int, user: CurrentUserDep, session: DbSessionDep) -> LikeResponse:
    """いいねを取り消す。いいねしていなければ何もしない。"""
    _ensure_post_exists(session, post_id)
    session.execute(delete(Like).where(Like.user_id == user.id, Like.post_id == post_id))
    session.commit()
    return _like_response(session, post_id, user.id)
```

def _find(posts: list[dict], post_id: int) -> dict:
    """投稿一覧から、指定した id の投稿を探す。"""
    return next(post for post in posts if post["id"] == post_id)


@pytest.mark.parametrize(
    ("method", "path"),
    [
        ("GET", "/posts"),
        ("POST", "/posts"),
        ("POST", "/posts/1/like"),
        ("DELETE", "/posts/1/like"),
    ],
)
def test_requires_login(client: TestClient, method: str, path: str) -> None:
    """T-02: 未ログインだと 4 つとも拒否する。"""
    response = client.request(method, path, json={"content": "こんにちは"})

    assert response.status_code == 401


def test_create_post(
    db_client: TestClient,
    create_user: Callable[..., UUID],
    login_as: Callable[[UUID], None],
) -> None:
    """T-03: 投稿できる。"""
    user_id = create_user("Aさん")
    login_as(user_id)

    response = db_client.post("/posts", json={"content": "こんにちは"})

    assert response.status_code == 201
    body = response.json()
    assert body["content"] == "こんにちは"
    assert body["image_url"] is None
    assert body["author"]["id"] == str(user_id)
    assert body["author"]["display_name"] == "Aさん"
    assert body["like_count"] == 0
    assert body["liked_by_me"] is False


def test_timeline_is_newest_first(
    db_client: TestClient,
    create_user: Callable[..., UUID],
    login_as: Callable[[UUID], None],
) -> None:
    """T-04: タイムラインが新しい順に並ぶ(同じ時刻なら id の大きい順)。"""

    assert ids.index(second_id) < ids.index(first_id)

def test_like_count_and_liked_by_me(

## 困ったときは

| 症状                                                                                  | 原因と対処                                                                                                                                         |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ModuleNotFoundError: No module named 'psycopg2'`                                     | 接続文字列が `postgresql://` のまま。`create_engine` に `sqlalchemy_database_url`(`+psycopg` 付き)を渡しているか確認                             |
| 接続時に `connection timeout` や `could not translate host name`                      | 開発用の Supabase が一時停止している、またはネットワークの問題。管理画面でプロジェクトを開き、停止中なら再開する                                   |
| 接続時に `password authentication failed`                                             | `.env` の `DATABASE_URL` のパスワードが違う。再発行した場合は書き換え忘れがないか確認                                                               |
| `Port could not be cast to integer` / 接続文字列の解析エラー                           | DB のパスワードに記号(`?` `/` `@` など)が入っている。英数字だけのパスワードに再発行する                                                          |
| `POST /posts` で `500` と `ForeignKeyViolation`                                        | ログイン中のユーザーの `profiles` がない。3.2 のトリガーが動いているか、Table Editor の `profiles` で確認する                                      |
| 日時が 9 時間ずれる                                                                   | `DateTime(timezone=True)` を付け忘れている                                                                                                         |
| `AttributeError: 'Insert' object has no attribute 'on_conflict_do_nothing'`           | `insert` を `sqlalchemy` から読み込んでいる。`from sqlalchemy.dialects.postgresql import insert` にする                                             |
