# WBS:jelgram

開発の進捗を管理する資料。各作業の具体的な手順は「手順書」列のファイルを参照する。

## 使い方

- 作業を始めたら状態を `作業中`、終わったら `完了` にして完了日を記入する
- 手順書が「作成予定」の作業は、着手前に手順書を作成してから進める
- 2次開発以降は、[要件定義書](要件定義書.md) 12章のロードマップに沿って、着手時に同じ形式で追記する

状態:`未着手` / `作業中` / `完了` / `保留`
