# WBS:jelgram

開発の進捗を管理する資料。各作業の具体的な内容は「資料」列のファイルを参照する。

## 使い方

- 状態の記号:⬜ 未着手 / 🔄 作業中 / ✅ 完了 / ⏸ 保留 / ➖ 対象外
- 作業を始めたら 🔄、終わったら ✅ にする。すべての工程が ✅ になったら完了日を記入する
- 1次開発は **モック先行** で進める([要件定義書](要件定義書.md) 7.4)
  - 工程 4:先に全画面のモック(Next.js + shadcn/ui・ダミーデータ)を作る
  - 工程 5:機能ごとに「API 仕様 → API → テスト → 画面接続 → 打鍵」の順に進める。API 仕様は `docs/API仕様/<ID>_<機能名>.md` に置き、「資料」列にリンクする
  - 4.1・4.2 は旧方式(詳細設計書・マニュアル)で実装済み。資料は `docs/詳細設計_手順/` に残している
- 2次開発以降は、要件定義書 12章のロードマップに沿って、着手時に同じ形式で追記する
