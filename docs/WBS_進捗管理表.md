# WBS:jelgram

開発の進捗を管理する資料。各作業の具体的な内容は「資料」列のファイルを参照する。

## 使い方

- 状態の記号:⬜ 未着手 / 🔄 作業中 / ✅ 完了 / ⏸ 保留 / ➖ 対象外
- 作業を始めたら 🔄、終わったら ✅ にする。すべての工程が ✅ になったら完了日を記入する
- 機能開発(4・5)は「詳細設計 → 製造 → テスト → 打鍵」の順に進める([要件定義書](要件定義書.md) 7.4)
  - 着手時に `docs/詳細設計_手順/<ID>_<機能名>/` フォルダを作り、`詳細設計書.md`(何を作るか・実装のヒント)と `マニュアル.md`(具体的な作業手順)を置く。「資料」列にリンクする
- 2次開発以降は、要件定義書 12章のロードマップに沿って、着手時に同じ形式で追記する
