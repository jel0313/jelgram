# 05 画像の拡大表示

| 項目     | 内容                                       |
| -------- | ------------------------------------------ |
| 場所     | 投稿の画像を押したとき、画面の上に重ねて表示 |
| フェーズ | 1次(要件定義書への追加。API は不要)      |
| コード   | `apps/web/components/posts/image-viewer.tsx` |

| PC | スマホ |
| --- | --- |
| ![PC](PC.png) | ![スマホ](スマホ.png) |

## 部品と動き

| 部品           | 動き                                         |
| -------------- | -------------------------------------------- |
| 画像           | 画面に収まる大きさで、縦横の比率を保って表示 |
| 「×」・背景・Esc | 閉じる                                     |

## 使うデータ

なし(投稿の `image_url` をそのまま表示する)
