# 07 ユーザーページ

| 項目     | 内容                                      |
| -------- | ----------------------------------------- |
| URL      | `/users/{id}`                             |
| フェーズ | 4次                                       |
| コード   | `apps/web/app/(main)/users/[id]/page.tsx` |

その人のプロフィールと、その人の投稿をインスタ風のグリッド(3 列)で表示する。

| PC | スマホ |
| --- | --- |
| ![PC](PC.png) | ![スマホ](スマホ.png) |

## 部品と動き

| 部品                         | 動き                                              |
| ---------------------------- | ------------------------------------------------- |
| アイコン・表示名             | 大きく表示                                        |
| 投稿・いいね・「〇〇から利用」 | 投稿の数、もらったいいねの合計(表示中の投稿から数える)、参加した年月 |
| 「プロフィールを編集」       | 自分のページにだけ出る。プロフィール編集(08)へ   |
| 投稿のグリッド               | その人の投稿だけを新しい順に。画像があれば画像、なければ本文を正方形で出す。押すと投稿詳細(03)へ。PC はマウスを乗せるといいね数 |

| 状態           | 表示                                   |
| -------------- | -------------------------------------- |
| 読み込み中     | プロフィールとグリッドの灰色の枠       |
| ユーザーがいない | 「ユーザーが見つかりません」         |
| 投稿 0 件      | 「まだ投稿がありません」               |

## 使うデータ

| モックの関数                        | 本物にするとき(予定)       |
| ----------------------------------- | ---------------------------- |
| `lib/api/users.ts` の `getUser`      | `GET /users/{id}`            |
| `lib/api/users.ts` の `getUserPosts` | `GET /users/{id}/posts`      |
