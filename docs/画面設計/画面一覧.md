# 画面一覧

モック(`apps/web`)の画面ごとに、画像と画面仕様を置いている。画像はモックから撮ったもの。

| No. | 画面                                         | URL                | フェーズ | 使う API(予定)                                  |
| --- | -------------------------------------------- | ------------------ | -------- | -------------------------------------------------- |
| 01  | [ログイン](01_ログイン/画面仕様.md)          | `/login`           | 1次      | Supabase Auth(API なし)                          |
| 02  | [タイムライン](02_タイムライン/画面仕様.md)  | `/`                | 1次      | `GET /posts`・`POST /posts`・いいね・画像アップロード |
| 03  | [投稿詳細](03_投稿詳細/画面仕様.md)          | `/posts/{id}`      | 1次      | `GET /posts/{id}`                                  |
| 04  | [AIチャット](04_AIチャット/画面仕様.md)      | 全画面の右(常駐) | 1次・5次 | `POST /chat`・`GET /chat/history`・`GET /chat/sessions` |
| 05  | [画像の拡大表示](05_画像の拡大表示/画面仕様.md) | (重ねて表示)     | 1次      | なし                                               |
| 06  | [投稿の編集・削除](06_投稿の編集・削除/画面仕様.md) | (重ねて表示)  | 2次      | `PATCH /posts/{id}`・`DELETE /posts/{id}`          |
| 07  | [ユーザーページ](07_ユーザーページ/画面仕様.md) | `/users/{id}`    | 4次      | `GET /users/{id}`・`GET /users/{id}/posts`         |
| 08  | [プロフィール編集](08_プロフィール編集/画面仕様.md) | `/settings/profile` | 4次 | `PATCH /me/profile`・画像アップロード              |
| 09  | [共通の表示](09_共通の表示/画面仕様.md)      | —                  | 1次      | なし                                               |

- 「使う API」は予定。正式な形は、機能ごとの API 仕様(`docs/API仕様/`)で決める
- 1次より後のフェーズの機能には、画面上に「2次」「4次」「5次」の印を付けている(その印の機能は、そのフェーズで API につなぐ)

## 画面のつながり

```
未ログイン
  └→ 01 ログイン ──(Google でログイン)──→ 02 タイムライン

ログイン後(どの画面でも、右に 04 AIチャット が常駐。スマホは右下のボタン)
  02 タイムライン
   ├─ 投稿の本文・日時 ────→ 03 投稿詳細
   ├─ 投稿者の名前・アイコン → 07 ユーザーページ ─(自分なら)─→ 08 プロフィール編集
   ├─ 画像 ─────────────→ 05 画像の拡大表示
   ├─ 自分の投稿の「…」 ───→ 06 投稿の編集・削除
   └─ 「この投稿について」 ──→ 04 AIチャット(その投稿について質問)

  左のメニュー(スマホは右上のアイコン)
   ├─ ホーム ──────→ 02 タイムライン
   ├─ プロフィール ───→ 07 ユーザーページ(自分)
   └─ ログアウト ────→ 01 ログイン
```
