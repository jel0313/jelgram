# 詳細設計:コメント(第2・3・7章)

対象:`app/comments/`

## 処理フロー

```
作成:見えない投稿 → 404 / コメント不可(投稿者以外)→ 403 / 禁止語 → 400
      insert comments + comment_count + 1 → 投稿者に通知 → commit
編集:見えないコメント → 404 / 書いた本人以外 → 403
削除:書いた本人 または 投稿者 → 論理削除・comment_count - 1
      投稿者が他人のコメントを消したら監査ログ(comment.delete_by_post_owner)
一覧:古い順。カーソルは最後のコメントの id。ブロック関係の人のコメントは出さない
```

## 関数一覧

| 関数 | 役割 |
|---|---|
| list_comments(session, post_id, viewer_id, cursor, limit) | 一覧 |
| create_comment・update_comment・delete_comment | 作成・編集・削除 |
| _to_response(row, viewer_id) | can_delete(自分 or 投稿者)を計算 |

## SQL

```sql
-- 一覧
select c.*, p.user_id as post_owner_id, a.username …
from comments c join posts p on p.id = c.post_id join profiles a on a.id = c.user_id
where c.post_id = :post_id and c.deleted_at is null and a.status = 'active'
  and <not_blocked(a)>
  and (cast(:after_id as bigint) is null or c.id > cast(:after_id as bigint))
order by c.id limit :limit + 1

-- 論理削除(2回目は何もしない。カウンタは1回だけ減る)
update comments set deleted_at = now() where id = :id and deleted_at is null returning id
```
