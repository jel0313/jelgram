# 詳細設計:通報・管理者(第7・15章)

対象:`app/admin/`・`POST /posts/{id}/report`

## 処理フロー

```
通報:見えない投稿 → 404 / 同じ人の2回目は無視(unique)→ 204
解決:require_role("admin")
      select … from reports where id = :id for update   ← 2人の管理者が同時に押しても1回だけ
      open でない → 409
      hide_post:posts.hidden_at = now → 同じ投稿の未処理の通報をまとめて resolved
      dismiss  :この通報だけ dismissed
      監査ログ → commit
凍結:status = suspended(管理者・退会済みは対象外)→ 以後その人は 403・投稿は誰にも見えない
自動判定(AI・Webhook):非表示 + 通報者なしの通報「[ai] 理由」→ 管理者が確認して戻せる
```

## 監査ログ(15-4)

| action | 記録するタイミング |
|---|---|
| report.hide_post・report.dismiss | 通報の処理 |
| post.hide・post.unhide・post.auto_hide | 投稿の非表示 |
| user.suspend・user.unsuspend | 凍結 |
| post.delete・comment.delete_by_post_owner・user.delete | 削除 |

各行に request_id を入れる。アクセスログと突き合わせて「どのリクエストか」まで追える。

## 例外

| 例外 | ステータス |
|---|---|
| ForbiddenError(管理者でない) | 403 |
| ReportNotFoundError | 404 |
| ReportAlreadyResolvedError | 409 |
