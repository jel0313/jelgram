### 変わったこと・反映したこと

| 変化 | 理由 | 反映 | 影響する問題 ID |
|---|---|---|---|
| HTTP クライアントは `httpx2`(Pydantic 社が保守する後継)。Starlette 1.x の TestClient は httpx2 を使い、httpx だと非推奨の警告を出す | Starlette が httpx2 を前提にした | 外部 API(Gemini・Storage)も httpx2 で書いた | 12-1・14-5 |
| FastAPI 本体に SSE(`fastapi.sse.EventSourceResponse` + ジェネレーター)が入った | 以前は StreamingResponse か外部ライブラリ | /chat/stream を本体の機能で実装 | 12-3 |
| FastAPI 本体に OpenTelemetry が入った(0.143 で自動設定は opt-in に) | opentelemetry-instrumentation-fastapi が不要に | `FastAPI(telemetry=…)`・`FASTAPI_OTEL_AUTO_CONFIGURE` を使う | 22-3 |
| `FastAPI(root_path=…)` が非推奨(0.146) | サーバー側で指定する方式に | 使っていない(バージョンは /api/v1 のルーター) | 16-2 |
| Query などの `**extra` が削除(0.155)| 不明な引数は TypeError | `json_schema_extra` を使う(該当なし) | 1-1 |
| 省略した値の既定値は検証されない(0.148)・JSON の null と省略を区別(0.151) | 入力の扱いが厳密に | PATCH で「null は不可」を明示的に検証 | 3-4 |
| Pydantic のジェネリクスは `class Page[T](BaseModel)`(PEP 695)で書ける | Python 3.12 以降の標準の書き方 | CursorPage・OffsetPage | 4-1 |
| Gemini API は API キーを `x-goog-api-key` ヘッダーで送れる | URL(?key=)はログに残りやすい | ヘッダーで送る | 8-6・12-1 |
